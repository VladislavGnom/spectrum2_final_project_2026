# 🚀 Быстрый старт демо-сайта «Робот-Забота»

## 1. Установка (30 секунд)

```bash
git clone <репозиторий>
cd robot_zabota
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py loaddata fixtures/demo_users.json fixtures/demo_robots.json
python manage.py runserver
```

## 2. Готово! Сайт доступен по адресу:

http://127.0.0.1:8000

## 4. Что смотреть

- **Главная** — лендинг с формой обратной связи
- **/catalog/** — каталог роботов (3 в наличии + 1 «Скоро в продаже»)
- **/blog/** — истории семей
- Войти как **user@zabota.ru** → добавить робота в корзину → оформить заказ → увидеть подтверждение
- **/admin/** — админка (войти как admin@zabota.ru): заявки с сайта, заказы, роботы, пользователи

## 5. Дополнительно

- Блог работает из коробки — истории захардкожены в `blog/cases.py`, отдельная фикстура не нужна
- Форма на главной странице сохраняет заявки в базу — они появятся в `/admin/core/contactrequest/` после отправки
- Статус робота «В наличии» / «Скоро в продаже» можно менять прямо в админке (`/admin/catalog/robot/`), не трогая код
- Робот «Забота-Мини» специально загружен со статусом «Скоро в продаже» — чтобы сразу показать эту функцию жюри без лишних кликов в админке

## 6. Если что-то пошло не так

- Пустая база после `migrate`, но `loaddata` ругается на отсутствие таблиц → убедитесь, что `migrate` отработал без ошибок до `loaddata`
- Ошибка `IntegrityError: UNIQUE constraint failed` при повторном `loaddata` → база уже содержит эти записи; либо удалите `db.sqlite3` и повторите `migrate` + `loaddata` с нуля, либо просто продолжайте работать с уже загруженными данными
